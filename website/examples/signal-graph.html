The Signal Graph, live

Fine-grained reactivity means work is proportional to the dependency graph, not the whole app. Nudge a, b, or c below and watch exactly which derived values and effects recompute — the highlights are driven by real front.js runs re-executing, not an animation.

Notice the two branches are independent: changing a or b recomputes a + b → × 2 → log₁, but never the c² branch — and vice-versa. Each node's badge counts how many times it has recomputed, so you can see the framework doing the minimum work. This is the same machinery walked through in How the Reactivity Works.
